# UI sample photographs

These Unsplash photographs are demonstration assets for the local CyberScan X
skin. They are not the user's photographs, Gold 200 captures or scanner output.
The client labels them as demo images. Local imports stay in browser memory.

Source URLs, retrieval date, file sizes and SHA256 values are recorded in
[sources.json](sources.json). Download/reuse was checked against the
[Unsplash license](https://unsplash.com/license) on October 30, 2026. The images
are served locally; the preview does not contact Unsplash or a scanner.

These image assets retain their Unsplash license; the repository MIT license
does not replace it. They are not offered as a competing image library.
